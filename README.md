# ZHARO App — APROBADO DIRECTO

Web para comerciales de ZHARO. **Este repositorio solo tiene el código de la web: nunca datos de clientes.**
Los casos, estados y PDF viven en el Apps Script / Drive privado de ZHARO, y solo los ve quien cargó el caso
(o un admin), con su login de Google. Quién puede entrar se define en las propiedades del Apps Script.
