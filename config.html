Login Google

Creá un OAuth Client ID (tipo Web) gratis en Google Cloud y pegalo acá. Orígenes autorizados: la URL de esta web.

Allowlist actual: allowed_users.json (leonel.cabrales91@gmail.com). Dominio @zharo más adelante.

Webhook del bot

Misma URL/clave que usa el poller de Telegram (ZHARO_WEBHOOK_URL + ZHARO_WEBHOOK_KEY). Se guardan solo en este navegador (localStorage), no en el repo.

El webhook de Cursor no acepta llamadas desde GitHub Pages (CORS). Con un token fine-grained (solo Actions write en leocabrales/zharo-app) el envío dispara la cotización real por script.

La pantalla de cotización pide <base>/<case_id>.json cada 2–3s. Vacío = default https://raw.githubusercontent.com/leocabrales/zharo-app/main/status.

Los casos de la web muestran el resultado en pantalla (reply_mode: web). No hace falta chat_id.
